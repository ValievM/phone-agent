# Ручная проверка: инструменты, вход, сборка, CI

Продолжение [manual-verification.md](manual-verification.md): те же правила (`[x]` ставит **только пользователь** после личной проверки на своём телефоне, агент пункты не отмечает; формат строки и порядок проверки описаны там). Здесь пункты про инструменты, настройки, вход, release-сборку, CI и логи.

## Не проверено пользователем лично

- [ ] `search_files` / `find_files` (`feat/47-search-quality`, #59): запросы `математика` и
  `за 3 часа математика` находят `Математика_за_3_часа.pdf`; `ёлка`/`елка` совпадают; `alternatives` работают
  через ИЛИ. `search_files` с `types: ["pdf"]` без запроса и с `.pdf` выдаёт одинаковые PDF по
  убыванию даты; короткий стем вместе с типом сужает список; совпадает имя непосредственной папки,
  но не папки-предка и не дата изменения. Пустой результат показывает попытки без имён/путей.
  `find_files` остаётся в выбранной SAF-папке и фильтрует по имени/типу; для более чем 20
  совпадений с разными датами изменения возвращает ровно 20 самых новых по убыванию даты;
  содержимое не читается.
- [ ] `notify` — уведомление реально появляется с нужным текстом; на API 33+ отказ в
  `POST_NOTIFICATIONS` даёт понятное сообщение, а не тихий провал (этап 4.6).
- [ ] Два вызова `notify` подряд дают два отдельных уведомления.
- [ ] Нажатие на уведомление открывает приложение.
- [ ] Открытие найденного файла через `ACTION_VIEW` из карточки `FilesFound` — открывается в
  дефолтном приложении, а если такого нет — показывается chooser, а не падение.
- [ ] Экран настроек (`ui/settings/`) — выбор модели реально меняет модель в следующем запросе;
  выход стирает токены; выбор SAF-папки переживает перезапуск, а `find_files` ищет только в
  выбранном дереве; очистка истории сразу обновляет открытый чат и отменяет активный ход без
  восстановления очищенной истории.
- [ ] «О приложении»: ссылка показывает подтверждение домена, «Отмена» не открывает браузер, а TalkBack объявляет «Проект <название>». Проверить перенос длинного держателя прав при 320dp и масштабе шрифта 200%, раскрытие лицензии после поворота, светлую и тёмную темы.
- [ ] Список моделей в настройках: загрузка, ошибка и пустой каталог объяснены, выбор в этих состояниях отключён; одна модель показана статично, несколько оставляют меню. На телефоне проверить актуальное число моделей и узкий экран при масштабе 200%.
- [ ] Logcat каталога моделей: успешная запись содержит только `count` и `http`; ошибка — тип исключения или HTTP-код. В записи нет slug моделей и токенов.
- [ ] Настройки → «Оформление»: на 320dp при масштабе шрифта 2.0 все три темы показаны вертикально и доступны через TalkBack; на обычной ширине сегменты равны. При смене темы цвета верхней панели синхронны с поверхностью экрана в настройках, «О приложении» и чате.
- [ ] Восстановление входа (`LoginRoute`): при запуске с уже выполненным входом виден нейтральный экран со знаком и индикатором до перехода в чат; без входа после восстановления появляется экран входа; поворот во время восстановления не показывает экран входа и не сбрасывает загрузку, добавлено Codex 2026-09-26.

- [ ] SAF-папка: отображается очищенное имя или fallback «Папка выбрана»; подсказка о
  «Загрузках» видна под кнопкой до открытия picker и после поворота; отмена сохраняет прежний выбор.
  Проверить длинное имя при ширине 320dp и масштабе шрифта 200%.
- [ ] Настройки → папка для поиска (`SearchFolderDisplayName.kt`, #56): при недоступном SAF URI показан fallback; WARN в Logcat содержит только `exceptionType`, без URI и текста исключения; добавлено GPT-1 2026-09-27.
- [ ] «Выйти и удалить историю»: история удалена; при ошибке очистки вход остаётся активным (`SettingsScreen`).
- [ ] «Выйти, историю оставить»: вход завершён, история чата сохранена (`SettingsScreen`).

- [ ] CI на GitHub ([tooling/ci.md](tooling/ci.md)): открыть вкладку Actions и убедиться, что последний запуск `check` зелёный. Claude проверил по `gh` 2026-09-25: запуск 36139162430 (`c4df4b4`) успешен за 9 мин 44 с; если позже упадёт, прислать лог упавшего шага, добавлено Claude 2026-09-24.
- [ ] Обновление токена без сети (`fix/session-race-and-transient`): когда токен уже просрочен и включён режим полёта, чат показывает «нет сети» с «Повторить», а не «сессия истекла»; после включения сети повтор работает без нового входа. То же, если сервер ответил 401, а обновить токен не удалось из-за сети (`fix/refresh-after-unauthorized-transient`, ловится редко: токен должен устареть на сервере раньше срока): «нет сети», не «сессия истекла». Гонку «выход во время обновления» руками воспроизвести трудно, она покрыта тестами, добавлено Claude 2026-09-24.

- [ ] Первый запрос разрешения не обрывается по таймауту (`fix/tool-pipeline-hardening`): сбрось разрешение приложения на уведомления или файлы (Настройки → Приложения → phone-agent → Разрешения), попроси «отправь уведомление» или «найди файл X» и **подожди больше 5 секунд**, прежде чем нажать «Разрешить»: инструмент должен отработать, а не вернуть «timed out after 5000ms».
