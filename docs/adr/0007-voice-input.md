# ADR 0007: голосовой ввод (слой 1, системный диалог распознавания)

Статус: принято 2026-10-01 (решение архитектора; владелец поручил распределить задачи эпика). Слой 2 ждёт отдельного решения владельца.

## Контекст
Нужна диктовка в поле ввода. Своего сервера распознавания и платного API нет, нового разрешения и новых зависимостей добавлять не хотим. В `conversation-domain-design.md` уже записано: голос подаёт текст тем же `Submit`, аудио это адаптер.

## Решение
1. **Слой 1**: системный диалог `RecognizerIntent.ACTION_RECOGNIZE_SPEECH` через Activity Result API. Разрешение `RECORD_AUDIO` и `<queries>` не нужны. Распознанный текст дописывается в черновик, отправка только нажатием.
2. Порт `SpeechInput` в `:core:domain` (один потребитель, но фейк и контракт нужны в `testFixtures`), адаптер `SystemDialogSpeechInput` и мост `SpeechRequestBridge` (Mediator, как `UserInteractionBridge`) в `:app/voice/`, без нового модуля.
3. Отдельная `VoiceInputViewModel`, `ChatViewModel` не трогаем. Результат в черновик идёт через состояние `Result(text, id)` и `ResultConsumed(id)`.
4. `VoiceHost` не отменяет запрос при уходе из композиции (запрос переживает поворот), в отличие от `InteractionHost`.
5. `SpeechRequest.offlineOnly` по умолчанию `false`: в Android флаг означает «только офлайн-движок», без языкового пакета диктовка падала бы при рабочей сети.
6. Правило Konsist: `android.speech` импортируется только в `com.example.phoneagent.voice`.
7. Логи: только `layer` и `outcome`, текст речи никогда.

## Альтернативы
- Слой 2 (`SpeechRecognizer.createOnDeviceSpeechRecognizer`, `RECORD_AUDIO`, живой текст, звук остаётся на устройстве): после решения владельца и проверки слоя 1 на телефоне.
- Своя запись + бэкенд: аудио в бэкенде не доказано.
- Whisper/Vosk в APK: +50–150 МБ, нативная зависимость.
- TTS (озвучка ответов), режим «без рук», автоотправка: не делаем.

## Последствия
- Звук обрабатывает сервис речи телефона; без офлайн-пакета он может уйти в облако поставщика. Это сказано в `design/a11y-security.md`.
- Пока диалог открыт, поверх виден чужой экран; текст по ходу речи не виден (это даст слой 2).
- Если на телефоне нет сервиса распознавания, ошибка `UNAVAILABLE` появится после нажатия (иконку не скрываем: для проверки наличия нужен `<queries>`).
- Смерть процесса при открытом диалоге теряет эту диктовку, черновик цел.
- Откат: revert задач эпика (#66–#75), данных и миграций нет.
